# Cafe Management System — project pack

Contents:
- `cafe-management-java-source-sanitized.zip`: Java source files provided by the owner, with database credentials and default seeded admin password removed.
- `screenshots/`: original application and MySQL schema screenshots provided by the owner.
- `mysql-schema.svg`: visual schema reference.
- `cms-schema-reference.sql`: reconstructed reference DDL based on the owner's MySQL DESCRIBE output, not an original database dump.

The source bundle is incomplete as a runnable project: it does not include the full NetBeans project metadata, model package, dependency JARs or original image-resource directory.
