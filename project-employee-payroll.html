01 / PROJECT OVERVIEW

Employee payroll management

This Class XII Informatics Practices project (academic year 2019–20) is titled Employee Payroll Management Software. The report documents a Java desktop application built using NetBeans and Swing, intended to manage employee records and payroll-related information.

02 / USER INTERFACE

Java Swing desktop interface

The report includes a welcome screen and login flow, followed by modules for employee record operations. Screenshots and code excerpts are included in the supplied report. The documented functions include adding, searching, updating and deleting employee records, managing family details, and updating salary and allowances.

03 / DATA & APPLICATION LAYER

Database connectivity

The source material describes a MySQL-backed application and shows JDBC-based database connectivity. The report includes code excerpts for connecting the Java application to the database and performing record-management operations.
