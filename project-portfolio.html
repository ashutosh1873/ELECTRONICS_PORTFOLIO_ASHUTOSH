01 / OBJECTIVE

A technical portfolio as a software project

This website is a personal web project designed to present an electronics-engineering profile through structured sections for research publications, projects, education, technical skills, certificates and contact information.

02 / FRONT END

Responsive static website

The current implementation uses HTML, CSS and vanilla JavaScript. It includes responsive navigation, a dark visual theme, publication search and category filters, project filtering, dedicated publication pages and project case studies.

03 / INFORMATION ARCHITECTURE

Research and project pages

The homepage acts as the central profile. Separate HTML pages are used for individual research publications and project case studies, while supporting PDFs are stored in the local assets directory. This keeps the site portable and suitable for static hosting.

04 / DEPLOYMENT

Static hosting

The project is designed for static hosting, including GitHub Pages. No server-side runtime is required for the current site. External links are used for DOI records, Coursera verification and public source repositories.
